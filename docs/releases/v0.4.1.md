Skylauncher 0.4.1 fixes two problems of 0.4.0 and a rare crash in Giants.

## Fixes
- **The game tools now follow the launcher.** After an update, the launcher gets the game tools of its own version before it builds a game. A Giants disc no longer fails with "is it Spyro's Adventure?".
- **Giants in every language of its disc.** Text and voices can be set separately, in any of the 12 languages: English, French, German, Spanish, Latin American Spanish, Italian, Dutch, Portuguese, Swedish, Norwegian, Danish and Finnish.
- **A rare crash when Giants starts** is fixed.
- **Giants' sidekicks** take the magic item place on the portal, as in the game.

## Install
1. Download Skylauncher for your system below.
2. Drop your own disc image on the window.
3. Click INSTALL, then PLAY. If you already have a game installed, Skylauncher updates it.

## Known issues
- Giants on Windows and Linux has not been tested on a real PC yet. Spyro's Adventure runs on both.
- The Mac app is not notarized: the first time, right-click it and choose Open. On Windows, SmartScreen may warn you: choose More info, then Run anyway.
