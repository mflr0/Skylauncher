Skylauncher 0.4.2 fixes 0.4.1 not opening on a Mac.

## Fixes
- **The Mac app opens again.** 0.4.1 could quit at start when macOS would not let it list a folder (as when the app has just been downloaded and is opened from Finder). The launcher now skips a folder it cannot read and carries on.

## Install
1. Download Skylauncher for your system below.
2. Drop your own disc image on the window.
3. Click INSTALL, then PLAY. If a game is already installed, Skylauncher offers to update it.

## Known issues
- Giants on Windows and Linux has not been tested on a real PC yet. Spyro's Adventure runs on both.
- The Mac app is not notarized: the first time, right-click it and choose Open. On Windows, SmartScreen may warn you: choose More info, then Run anyway.
