Skylauncher 0.4.3 fixes two freezes and brings game fixes for Spyro's Adventure and Giants.

## Fixes
- **The launcher no longer freezes** when a line of text in the sidebar (such as a download progress in French) does not fit its column. It is now cut with "..." instead.
- **Resizing the game window no longer freezes the game.** In a level, the game could stop for good, with a pink window, while its window was being resized.

## Game updates
Skylauncher offers to update an installed game.
- **Spyro's Adventure:** the grass on the Heroic Challenge islands is drawn again, and levels load faster on Windows.
- **Giants:** a second player can join with a second controller, the Wow Pow can be set from the Toy Box, and one more effect is drawn.

## Install
1. Download Skylauncher for your system below.
2. Drop your own disc image on the window.
3. Click INSTALL, then PLAY.

## Known issues
- Giants on Windows and Linux has not been tested on a real PC yet. Spyro's Adventure runs on both.
- The Mac app is not notarized: the first time, right-click it and choose Open. On Windows, SmartScreen may warn you: choose More info, then Run anyway.
