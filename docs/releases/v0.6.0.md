Skylauncher is now **Arkeyan Launcher**. Your games, settings, collection and desktop shortcuts carry over: nothing to do.

## The new name
- The window, the menus, the About page, the app and the files are called Arkeyan Launcher (`ArkeyanLauncher.exe`, `ArkeyanLauncher-macOS.dmg`, `ArkeyanLauncher-x86_64.AppImage`). The macOS bundle id is unchanged, so macOS does not ask for folder permissions again.
- A launcher you already have updates itself in place and keeps its file name (`Skylauncher.exe`, `Skylauncher.app`...). The release also carries the files under their old names so that Skylauncher 0.4.x can find the update.
- Desktop shortcuts made by Skylauncher keep working; the launcher rewrites them at its next start so they carry the new name.
- The game kit is now `skylanders-kit-<platform>.zip` (also published as `ssa-kit-<platform>.zip`), with `SkyBuild` as its builder (`SSABuild` stays next to it for older launchers).
- Environment variables are now `SKY_*` and `SKY_LAUNCHER_*`; the earlier `SSA_*`, `SKYLAUNCHER_*` and `SSA_LAUNCHER_*` names are still read.

## Fixes
- "Uninstall everything" works when a folder is reached through a link (as a temporary folder is on macOS).

## Install
1. Download Arkeyan Launcher for your system below.
2. Drop your own disc image on the window.
3. Click INSTALL, then PLAY. If a game is already installed, Arkeyan Launcher offers to update it.

## Known issues
- The Mac app is not notarized: the first time, right-click it and choose Open. On Windows, SmartScreen may warn you: choose More info, then Run anyway.
